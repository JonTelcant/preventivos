🗺️ Comparar Preventivos con Emplazamientos

ℹ️ Información

Sube los archivos de preventivos y emplazamientos para generar un CSV con las coordenadas.

Requisitos de los archivos:

  • Ambos deben ser archivos Excel (.xlsx)
  • El archivo de preventivos debe tener los datos en la primera hoja
  • El archivo de emplazamientos debe tener los datos en la primera hoja

Proceso:

  • Se formatean los nombres de emplazamientos eliminando patrones comunes (2G, 3G, 4G, C.T., etc.)
  • Se buscan coincidencias entre preventivos y emplazamientos usando un índice de similitud > 0.7
  • Se genera un CSV con formato para Google Maps
